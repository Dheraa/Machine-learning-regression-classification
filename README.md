**Project Overview**

This project explores two supervised machine learning techniques: Linear Regression and Logistic Regression.

The objective was to apply machine learning algorithms to practical prediction problems involving used laptop prices and loan repayment outcomes.

**Problem Statements**

**1. Used Laptop Price Prediction**

Developed a Linear Regression model to estimate laptop prices based on:

• RAM capacity
• Storage capacity
• Laptop age

**Model Performance:**

• R² Score: 0.929
• Mean Absolute Error: 21.28
• Root Mean Squared Error: 28.08

**2. Loan Repayment Prediction**

Developed a Logistic Regression classifier to predict whether a loan applicant would repay a loan.

The model used applicant information such as monthly income, loan amount, employment duration and previous defaults.

**Model Performance:**

• Test Accuracy: 72.5%
• Precision at a 0.7 threshold: 81.8%
• Recall at a 0.7 threshold: 45%

A Decision Tree classifier was also evaluated, achieving 61.25% test accuracy compared with Logistic Regression’s 72.5%.
